# ai-ch — приватный ИИ-сайт с озвучкой и архивом ответов

Веб-приложение на FastAPI с авторизацией, потоковым выводом ответа, Markdown/формулами/кодом и загрузкой документов. Стиль адаптирован под deepseekw/ai-ch: тёплый бумажный фон, песочная боковая панель, тонкие границы и терракотовые акценты.

## Что реализовано

- Основная модель задаётся через `AI_API_BASE_URL`, `AI_API_KEY`, `AI_MODEL`; API должен быть совместим с OpenAI Chat Completions.
- `AI_FALLBACK_MODELS` задаёт запасные модели через запятую.
- По умолчанию основной ответ сайта использует ENV-модель прежде любых маршрутов в БД. Поставь `AI_ENV_PRIORITY=0`, чтобы разрешить маршруту AI Router иметь приоритет; ENV-модель также остаётся запасным вариантом, когда маршрут не настроен.
- `GLOBAL_AI_CONCURRENCY` ограничивает количество одновременно выполняемых запросов к AI API на процесс приложения.
- Независимый TTS API задаётся через `TTS_API_BASE_URL`, `TTS_API_PATH`, `TTS_API_KEY`, `TTS_MODEL`, `TTS_VOICE`. По умолчанию ожидается OpenAI-совместимый endpoint, возвращающий бинарный MP3.
- Каждый завершённый ответ автоматически отправляется в Telegram-канал через `TELEGRAM_BOT_TOKEN` + `ARCHIVE_CHANNEL_ID`. При рабочей TTS-конфигурации дополнительно публикуются MP3-фрагменты.
- История диалога держится только в ограниченной RAM-памяти процесса, чтобы работали уточнения в одной открытой сессии. Тексты сообщений, записи запросов и файлы удаляются после ответа; при рестарте RAM-контекст исчезает. Учётные записи остаются в SQLite.
- Старые сохранённые сообщения и файлы очищаются при первом старте этой версии.

## Переменные окружения

Минимальная конфигурация:

```dotenv
AI_API_BASE_URL=https://llm.stage.satel.org/v1
AI_API_KEY=ВАШ_КЛЮЧ_ОСНОВНОЙ_МОДЕЛИ
AI_MODEL=qwen36-35b
AI_ENV_PRIORITY=1
GLOBAL_AI_CONCURRENCY=2

TTS_API_BASE_URL=https://openrouter.ai/api/v1
TTS_API_PATH=/audio/speech
TTS_API_KEY=ВАШ_TTS_КЛЮЧ
TTS_MODEL=fish-audio/s2.1-pro-free:free

TELEGRAM_BOT_TOKEN=ТОКЕН_БОТА
ARCHIVE_CHANNEL_ID=-1001234567890
```

Подставь действующие адреса, названия моделей и ключи из кабинетов своих провайдеров. TTS использует **свой отдельный ключ**. Возможность аудио-генерации зависит от конкретного TTS-провайдера и его API.

Для публикаций создай канал Telegram, добавь бота администратором с правом публикации сообщений и укажи числовой ID канала (часто начинается с `-100`). Если канал закрытый, ответы остаются доступны участникам канала. Не указывай публичный канал, если ответы могут содержать приватные данные: каждый ответ будет пересылаться туда автоматически.

## Render

В репозитории есть `render.yaml`. Runtime — **Docker**, Dockerfile Path — `./Dockerfile`, Root Directory оставь пустым. Отдельные Build Command и Start Command не заполняются: Dockerfile устанавливает пакеты и запускает Uvicorn.

Сервер слушает `0.0.0.0:$PORT`, порт по умолчанию — `10000`; Render самостоятельно направляет HTTPS-трафик на этот порт. Health check — `/api/health`. После создания сервиса добавь ключи в Environment и выполни Manual Deploy → Deploy latest commit.

Бесплатный Render использует временную файловую систему. Без постоянного диска/внешней БД пользовательские аккаунты, хранящиеся в SQLite, могут сбрасываться после рестартов/переразмещения. История переписки и так намеренно не сохраняется.

## Локальный запуск

Требуется Python 3.12+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
uvicorn backend.app:app --host 0.0.0.0 --port 10000
```

После запуска сайт будет доступен по адресу `http://localhost:10000`; Docker Compose публикует его на `http://localhost:3050`.

## Проверки

- `GET /api/health` — HTTP liveness, лимит конкурентности и наличие основных ENV-переменных.
- Проверь последовательно текстовый ответ, его публикацию в канале, затем TTS-аудио.
- Если ответ виден на сайте, но не появился в канале, проверь логи Render, ID канала и права бота. Сбой архива/TTS не должен ломать текстовый ответ сайта.
