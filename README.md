# chatai — Telegram ИИ-ответчик с озвучкой

Отдельный Python-проект: ИИ отвечает на текстовые вопросы и фотографии, подготавливает специальный сценарий русской озвучки и отправляет в Telegram ответ текстом, голосовое сообщение и отдельный MP3. При наличии закрытого архивного канала бот сохраняет туда текст и оба аудиосообщения.

## Возможности

- Диалог с памятью последних сообщений; команда /new очищает историю.
- Текстовые задания и фотографии (например, фото упражнения).
- OpenAI-совместимый API языковой модели с резервным списком моделей.
- Независимый TTS API, выбор голоса и скорости.
- Отдельные правила произношения математических формул, дробей, степеней, скобок, геометрии, физики и кода.
- Длинная речь делится на части и собирается в MP3; ffmpeg создаёт OGG/Opus для голосового сообщения.
- Отправка MP3 как отдельного скачиваемого аудиофайла.
- Копирование текста, голосового сообщения и MP3 в канал-архив.
- Локальный polling; webhook и endpoint /healthz для Render.

## Бесплатные модели по умолчанию

Шаблон настроен на OpenRouter:
- AI_MODEL = openrouter/free — маршрутизатор доступных бесплатных моделей.
- TTS_MODEL = fish-audio/s2.1-pro-free:free — бесплатная TTS-модель для тестов и небольших нагрузок.

Бесплатные маршруты ограничены доступностью, квотами и скоростью. Это не гарантия непрерывного бесплатного сервиса или постоянного качества. Проверь модель и голос на своём ключе. Если провайдер изменит slug или доступность, обнови переменные окружения. Цена языковой модели зависит от выбранного маршрута; не подставляй платную модель, не проверив тариф.

## Локальный запуск

Требуются Python 3.12+ и ffmpeg (для голосовых сообщений в OGG/Opus).

1. Скопируй файл .env.example в .env.
2. Создай Telegram-бота через @BotFather и заполни TELEGRAM_BOT_TOKEN.
3. Запусти приложение и отправь боту команду /id. Вставь свой числовой ID в ALLOWED_USER_IDS и перезапусти приложение. Пока список доступа пуст, бот не обрабатывает задания.
4. Добавь API-ключ в AI_API_KEY. По умолчанию используется OpenRouter и бесплатный маршрутизатор openrouter/free.
5. Запусти команды:

   python -m venv .venv

   Windows PowerShell: .venv\Scripts\Activate.ps1

   macOS/Linux: source .venv/bin/activate

   pip install -r requirements.txt

   python main.py

Если WEBHOOK_URL не задан, бот использует polling. HTTP-сервер слушает порт 8000 или значение PORT.

## Развёртывание на Render

1. Создай Web Service из репозитория или используй Blueprint render.yaml.
2. Заполни TELEGRAM_BOT_TOKEN, ALLOWED_USER_IDS и AI_API_KEY.
3. Для озвучивания по умолчанию берётся AI_API_KEY. Если TTS-провайдер отдельный, добавь TTS_API_KEY.
4. На Render приложение читает RENDER_EXTERNAL_URL и регистрирует webhook автоматически. Не указывай /telegram/webhook в WEBHOOK_URL вручную.
5. Для архива создай приватный канал, добавь бота администратором с правом публикации и укажи ARCHIVE_CHANNEL_ID (обычно идентификатор начинается с -100).

Проверка работоспособности сервиса: endpoint /healthz.

### Ограничения бесплатного Render

Бесплатный Web Service может засыпать после периода без входящего трафика, а локальные файлы теряются при сне, перезапуске или redeploy. Поэтому SQLite на бесплатном Render не является постоянной базой данных, и первое сообщение после простоя может обрабатываться с задержкой. Для устойчивой истории нужна внешняя PostgreSQL или хостинг с постоянным диском. Аудио и текст, уже опубликованные в Telegram-архиве, останутся в канале.

## Настройка TTS

OpenRouter принимает запросы синтеза речи через endpoint /api/v1/audio/speech и возвращает аудиобайты. Голоса зависят от конкретной модели. Если voice=default не поддерживается выбранным провайдером, поставь допустимое имя через TTS_DEFAULT_VOICE или команду /voice. Скорость меняется командой /speed 1.1; некоторые модели могут игнорировать параметр speed.

Параметры:
- TTS_API_BASE_URL — базовый URL провайдера.
- TTS_API_KEY — отдельный ключ; если пустой, переиспользуется AI_API_KEY.
- TTS_MODEL и TTS_FALLBACK_MODELS — основной и запасные TTS-модели.
- TTS_DEFAULT_VOICE — голос по умолчанию.
- TTS_DEFAULT_SPEED — скорость от 0.5 до 2.0.
- TTS_CHUNK_CHARS — длина фрагмента для генерации.
- TTS_MAX_CHARS — защита от слишком длинной и потенциально дорогой озвучки.

## Команды

- /start — приветствие и справка.
- /new — очистить историю диалога.
- /voice название — выбрать TTS-голос.
- /speed 1.1 — установить скорость от 0.5 до 2.0.
- /settings — посмотреть выбранный голос и скорость.
- /id — узнать свой Telegram ID.

## Безопасность и важные детали

- Не коммить файл .env и не помещай API-ключи в исходники.
- Обязательно настрой ALLOWED_USER_IDS, иначе бот не обрабатывает пользовательские запросы.
- Для анализа фотографий нужна AI-модель с поддержкой изображений. Бесплатный маршрутизатор старается выбирать модель с нужной модальностью, но доступность зависит от текущих моделей.
- Корректность озвучивания формул зависит и от сценария, сформированного языковой моделью, и от самого TTS. Проверь примеры с интегралами, дробями, скобками, геометрией и кодом.
- Telegram ограничивает отправляемые аудиофайлы примерно 50 МБ. Очень длинный ответ нужно сокращать или делить на несколько файлов.
